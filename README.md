<summary>🚀 Template setup checklist — delete this section before going public</summary>

**Quick start:** Run `sh scripts/init-template.sh` to fill in all placeholders automatically, or do it manually:

1. Replace every placeholder in this repo:
   - `<PROJECT_NAME>` → your project name
   - `<DESCRIPTION>` → one-line description of what your project does
   - `<OWNER>` → your GitHub username or organization name
   - `<YEAR>` → current year
   - `<COPYRIGHT_HOLDER>` → your name or organization
   - `<CONTACT_EMAIL>` → email address for Code of Conduct reports
   - `<SECURITY_CONTACT>` → email or URL for security vulnerability reports

2. Choose a license: the default is MIT. Swap `LICENSE` if you want a different one.

3. Go to **GitHub → Settings → Template repository** and enable it.

4. Go to **GitHub → Settings → Code security** and enable Dependabot.

5. Create these labels in your repo (GitHub → Issues → Labels). Release Drafter uses them to write release notes automatically:
   - `major`, `minor`, `patch`
   - `feature`, `enhancement`
   - `fix`, `bug`, `bugfix`
   - `chore`, `maintenance`
   - `docs`, `documentation`
   - `dependencies`

6. Delete this checklist block from `README.md`.

7. Delete `scripts/init-template.sh` (or keep it for new repos).
