Installation

One command.
Everything configured.

Clone the template, run the init script, and start building — no boilerplate hunting, no manual setup.

  1. 01

    Clone the repository

    Grab a local copy of the template.

    git clone https://github.com/wannacry081/genesis
  2. 02

    Run the setup script

    The init script replaces all placeholders with your project details.

    sh scripts/init-project.sh

    Or, if make is installed:

    make init
  3. 03

    Follow the prompts

    Fill in your project name, description, owner, and contacts. The script removes itself, README.md, and .gitignore so you start completely fresh.
